# Examples

Plain markdown memos with tasks mixed in — paste them in and the task layer appears. Full syntax: [TASK_FORMAT.md](TASK_FORMAT.md).

## Work note

```markdown
#work

Client wants the auth flow fixed before the Nov demo, this is the top priority.
Migration tests are blocked on the staging DB snapshot, chasing DevOps.
Deploy freeze starts Wednesday afternoon — everything must ship before that.
Onboarding copy still needs final sign-off from Sarah.

- [ ] fix auth timeout 2026-11-03 p1 #backend
- [ ] review PR today 2pm !15min p2
- [ ] update onboarding copy tomorrow 5pm !30min #frontend
- [ ] write migration tests 2026-11-05 #backend
- [x] sync with DevOps on DB snapshot
```
